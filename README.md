# Simontine

Hi, I’m Simontine — a Software Engineer and DevOps Engineer who enjoys building both websites and hardware-controlled devices.

I work with technologies like Angular, Vue, React, and Node.js to create web experiences, and I also build embedded and connected systems using Arduino boards, ESP32 devices, and Raspberry Pi. I like combining software and hardware to create practical, useful projects.

One of my proudest projects is a smart wheelchair project, which reflects my interest in using technology to improve everyday life.

I’m professional in my work, but I also like to keep things creative, hands-on, and personal.
