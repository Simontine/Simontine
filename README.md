# Simontine

## Software Engineer • DevOps Engineer • Builder

I’m Simontine — I build with purpose.

I work at the intersection of software, hardware, and automation, creating websites and hardware-controlled devices that solve real problems and bring ideas to life. My toolkit includes Angular, Vue, React, Node.js, Arduino, ESP32, and Raspberry Pi.

I enjoy crafting clean web experiences, wiring up connected systems, and turning concepts into reliable products. One of the projects I’m especially proud of is my smart wheelchair initiative — a project that reflects my interest in using technology to make a meaningful difference.

### What I Do

- Automate and deploy systems with DevOps workflows
- Explore projects where software meets hardware

### Tools I Work With
- Frontend: Angular, Vue, React
